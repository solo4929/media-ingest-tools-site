プライバシーポリシー

最終更新日：2026年10月11日

このポリシーは、Multimedia Renamer（media-ingest-tools、以下「本アプリ」）が Google ユーザーデータをどう扱うかを説明するものです。

本アプリが利用する Google ユーザーデータ

本アプリが要求する権限は、Google フォト ライブラリへの写真の追加（https://www.googleapis.com/auth/photoslibrary.appendonly）だけです。利用者のライブラリにある写真・アルバム・その他の Google アカウント情報は読み取りません。

データの使い方

利用者が選んだ写真を、利用者本人の Google フォト ライブラリにアップロードするためだけに使います。それ以外の目的には使いません。

データの保存

認証で受け取るアクセストークンとリフレッシュトークンは、本アプリを実行している利用者の Mac の中にだけ保存します（本人だけが読めるファイル）。本アプリの開発者や外部のサーバーには送りません。

第三者への提供

Google ユーザーデータを第三者に提供・販売・共有することはありません。写真の送り先は Google の API だけです。

Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリが Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消しとデータの削除

本アプリへのアクセスは、Google アカウントのサードパーティ アクセス設定からいつでも取り消せます。Mac に保存したトークンは、本アプリの設定フォルダ（~/Library/Application Support/media-ingest-tools/）から削除できます。
